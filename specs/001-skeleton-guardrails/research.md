## Spring Boot 3 → 4 changes that matter here

Taken from the official Spring Boot 4.0 migration guide (see the pitfalls table in the constitution):
modular starters (`spring-boot-starter-webmvc`, `spring-boot-starter-flyway`), technology test starters,
Jackson 3 (`tools.jackson.*`), `@MockitoBean`, `@AutoConfigureMockMvc` / `@AutoConfigureRestTestClient` no
longer implied by `@SpringBootTest`, `RestTestClient` as the preferred HTTP test client.

## Decisions taken in this plan

- **Maven Wrapper from Initializr** instead of hand-writing it: avoids an invented wrapper version.
- **Surefire for `*Test`, Failsafe for `*IT`**: unit tests stay fast and Docker-free (`./mvnw test`).
- **`cucumber.junit-platform.discovery.as-root-engine=false`**: features run only through `CucumberIT`, never
  twice.
- **Traceability reads compiled test classes with ArchUnit's importer**: no extra classpath-scanning library.
- **No database volume in Compose**: every restart starts from the seed data, which makes demos repeatable.
